# سایت اروم زمین بهسازان (Orum Zamin Behsazan)
راهنمای کامل و قدم‌به‌قدم انتشار روی Cloudflare Pages — از صفر تا سایت زنده

این پروژه از **Cloudflare Pages Functions** و **Cloudflare KV** استفاده می‌کند تا فرم تماس، پنل مدیریت، و بخش مقالات به‌صورت واقعی و دائمی کار کنند.

⚠️ **نکته‌ی خیلی مهم:** آپلود مستقیم (drag & drop) در داشبورد کلودفلر از پوشه `functions` پشتیبانی نمی‌کند. برای اینکه بخش‌های زنده‌ی سایت (فرم تماس، پنل مدیریت، مقالات) کار کنند، **باید** از روش «Wrangler» (خط فرمان) استفاده کنید — نه آپلود ساده‌ی فایل.

---

## مرحله ۰ — پیش‌نیازها

1. یک حساب رایگان در [cloudflare.com](https://cloudflare.com) بسازید (اگر ندارید).
2. **Node.js** را نصب کنید — از [nodejs.org](https://nodejs.org) نسخه‌ی LTS را دانلود و نصب کنید (نصب معمولی، بعدی-بعدی-پایان).
3. فایل zip پروژه را دانلود و در یک پوشه روی کامپیوترتان **Extract/استخراج** کنید (مثلاً در Desktop).
4. یک ترمینال باز کنید:
   - ویندوز: در پوشه‌ی استخراج‌شده، کلیک راست کنید و «Open in Terminal» یا «Open PowerShell here» را بزنید.
   - مک: برنامه‌ی Terminal را باز کنید و با دستور `cd` به پوشه بروید، مثلاً:
     ```
     cd ~/Desktop/orum-zamin-behsazan-cf
     ```

از اینجا به بعد همه‌ی دستورها را داخل همین ترمینال، داخل پوشه‌ی پروژه اجرا کنید.

---

## مرحله ۱ — ورود به حساب کلودفلر

```
npx wrangler login
```
یک تب مرورگر باز می‌شود؛ روی «Allow» بزنید تا وارد حساب کلودفلر شوید. بعد از دیدن پیام موفقیت در ترمینال، می‌توانید تب مرورگر را ببندید.

---

## مرحله ۲ — ساخت پایگاه داده (KV Namespace)

این پایگاه داده جایی است که محتوای سایت، مقالات، و پیام‌های مشتریان ذخیره می‌شود.

```
npx wrangler kv namespace create OZ_KV
```

خروجی چیزی شبیه این می‌دهد:
```
{ binding = "OZ_KV", id = "a1b2c3d4e5f6g7h8..." }
```

مقدار `id` را کپی کنید.

سپس فایل `wrangler.toml` را با یک ویرایشگر متن ساده (مثل Notepad یا VS Code) باز کنید و به‌جای `REPLACE_WITH_YOUR_KV_NAMESPACE_ID` همان مقدار `id` را جای‌گذاری و ذخیره کنید.

---

## مرحله ۳ — ساخت پروژه Pages

```
npx wrangler pages project create orum-zamin-behsazan
```
- وقتی نام برنچ تولید (production branch) را پرسید، Enter بزنید تا مقدار پیش‌فرض (`main`) انتخاب شود.

---

## مرحله ۴ — انتشار سایت

```
npx wrangler pages deploy public
```

بعد از چند ثانیه، آدرس سایت شما را در خروجی می‌بینید، چیزی شبیه:
```
https://orum-zamin-behsazan.pages.dev
```

این آدرس را باز کنید — سایت باید کاملاً نمایش داده شود (انیمیشن سه‌بعدی، بخش‌ها و...).

---

## مرحله ۵ — بررسی اتصال پایگاه داده

چون در `wrangler.toml` بایندینگ KV را از قبل تنظیم کردیم، دستور `deploy` باید آن را خودکار متصل کرده باشد. برای اطمینان:

1. وارد سایت شوید و پایین صفحه روی **«پنل مدیریت»** بزنید.
2. رمز پیش‌فرض: `orum1404`
3. اگر وارد پنل شدید، یعنی اتصال درست است ✅

اگر خطای ورود یا مشکلی دیدید:
- به داشبورد کلودفلر بروید: **Workers & Pages → پروژه `orum-zamin-behsazan` → Settings → Functions → KV namespace bindings**
- «Add binding» بزنید: Variable name = `OZ_KV`، و namespace همانی که در مرحله ۲ ساختید را انتخاب کنید.
- سپس یک‌بار دیگر مرحله ۴ (`npx wrangler pages deploy public`) را اجرا کنید.

---

## مرحله ۶ — تغییر رمز عبور (حتماً انجام دهید)

1. داخل پنل مدیریت، تب **«تنظیمات»** را باز کنید.
2. رمز فعلی (`orum1404`) و یک رمز جدید دلخواه وارد کنید و «به‌روزرسانی رمز» را بزنید.

---

## استفاده از پنل مدیریت

پس از ورود، چهار تب می‌بینید:

**۱. محتوای سایت** — عنوان هیرو، آمار، فعالیت‌ها، مراحل کار، دوره‌های آموزشی (با امکان افزودن/حذف دوره)، و اطلاعات تماس. پس از ویرایش، روی «ذخیره تغییرات» پایین صفحه بزنید.

**۲. مقالات** — روی «+ مقاله جدید» بزنید، عنوان و متن مقاله را بنویسید. اگر تیک «انتشار عمومی» را بردارید، مقاله به‌صورت پیش‌نویس ذخیره می‌شود و روی سایت نمایش داده نمی‌شود تا وقتی آماده باشید. هر مقاله در آدرس اختصاصی خودش (`سایت‌شما/articles/شناسه`) قابل مشاهده و اشتراک‌گذاری است.

**۳. پیام‌های دریافتی** — نام، تلفن، ایمیل و توضیحات هر کسی که فرم تماس را پر کرده، همراه با امکان دانلود CSV و حذف.

**۴. تنظیمات** — تغییر رمز عبور و خروج از پنل.

---

## به‌روزرسانی سایت در آینده

اگر بعداً بخواهید کدهای سایت را (نه محتوا، بلکه طراحی/ساختار) تغییر دهید، فایل‌ها را ویرایش کنید و دوباره اجرا کنید:
```
npx wrangler pages deploy public
```

---

## اتصال دامنه‌ی اختصاصی (اختیاری)

اگر یک دامنه مثل `orumzaminbehsazan.ir` یا `.com` دارید:
1. داشبورد کلودفلر → پروژه شما → **Custom domains** → **Set up a custom domain**
2. دامنه را وارد کنید و مراحل راهنمای روی صفحه را دنبال کنید (تنظیم DNS).

---

## روش جایگزین: اتصال ریپوی GitHub (برای انتشار خودکار)

اگر با گیت‌هاب راحت‌تر هستید:
1. کد پروژه را در یک ریپوی GitHub قرار دهید.
2. داشبورد کلودفلر → **Workers & Pages → Create → Pages → Connect to Git**
3. ریپو را انتخاب کنید. تنظیمات:
   - Build command: خالی بگذارید
   - Build output directory: `public`
4. بعد از اولین دیپلوی: **Settings → Functions → KV namespace bindings** → بایندینگ `OZ_KV` را اضافه کنید.
5. یک دیپلوی جدید بزنید («Retry deployment») تا بایندینگ اعمال شود.

## نکات امنیتی

- رمز عبور به‌صورت هش‌شده (SHA-256) در KV ذخیره می‌شود، نه متن ساده.
- نشست ورود (session) بعد از ۸ ساعت به‌طور خودکار منقضی می‌شود.
- این یک سامانه احراز هویت سبک برای یک سایت شرکتی کوچک است، نه یک زیرساخت امنیتی سازمانی؛ اگر داده‌های حساس‌تری قرار است ثبت شود، بهتر است با یک سیستم احراز هویت کامل‌تر (مثل Cloudflare Access) ترکیب شود.

## مشکلی پیش آمد؟

- **پنل مدیریت باز نمی‌شود / رمز اشتباه است:** مرحله ۵ (بررسی اتصال KV) را دوباره چک کنید.
- **فرم تماس ارسال نمی‌شود:** مطمئن شوید سایت را از طریق `wrangler pages deploy` منتشر کرده‌اید، نه با drag & drop.
- **مقاله باز نمی‌شود (۴۰۴):** مطمئن شوید تیک «انتشار عمومی» هنگام ذخیره مقاله فعال بوده است.
